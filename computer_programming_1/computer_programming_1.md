# Computer Programming 1

## What is Computer Programming 1?
Computer Programming 1 is, as the name suggests, an introductory course to programming.  

While the content of the course has complete beginners in mind (it starts from absolute zero and goes up to simple data structures), it should not be underestimated. The final exam requires students to come up with solutions quickly, as there is little time for trial and error.  

## The environment
Because of the time restrictions, I highly recommend that you replicate and practice on an environment that is as close as possible to the one you will be taking the exam on. If you're my classmate, for us it means to get as proficient as possible with the following software:
- Ubuntu 20.04 LTS
    - Ubuntu is the Linux distribution we will be using. If I find some spare time to do it I will make a dedicated tutorial on that, but what is important is that you get comfortable with using basic terminal commands, and to do so you have three options (ordered by how I would personally do it):
        - WSL (Windows Subsystem for Linux) (obviously Windows only)
        - a Virtual Machine
        - dual booting
        - switching your OS to Ubuntu (in my opinion there are better distros to choose from once you feel ready) 
- GNU Compiler Collection (`g++`)
    - g++ is the only reliable way to compile your code. Though you could get by with the GUIs in VSC and CLion, in the case that they stop working (which I have been told by our professor does happen pretty often) you should be ready to use them.
- Visual Studio Code
    - VSC is arguably the most used text editor for programming in the world. It is relatively intuitive and easy to pick up.
