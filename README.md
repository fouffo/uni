# uni
This repository was made to store and share any material I come across or produce that may be helpful to the future me or other students to get ready for exams.  
The general structure should be somewhat like this:
```
.
├── subject_name_1
│   ├── exercises
│   │   ├── assignment_name
│   │   │   ├── ex1.cpp
│   │   │   ├── ex2-1.cpp
│   │   │   ├── ex2-2.cpp
│   │   │   ├── ex3.cpp
│   │   │   └── exercises.pdf
│   │   └── other_assignment_name 
│   ├── resources
│   │   └── lesson1.pdf
│   └── subject.md  
├── subject_name_2
...
```
It will adapt to each subject, therefore expect some differences.
